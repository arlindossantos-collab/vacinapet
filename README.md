# 💉 Carteira Vacinal Digital Pet

Aplicativo web para gestão e acompanhamento do histórico vacinal dos seus pets com sincronização em tempo real na nuvem.

## 🚀 Funcionalidades
* **Gerenciamento de Pacientes:** Cadastro de cães e gatos com pelagem, cor base, peso, microchip e tutores.
* **Histórico de Vacinas:** Controle de vacinação aplicada, doses futuras, clínicas veterinárias e responsáveis técnicos.
* **Sincronização em Tempo Real:** Conectado ao Firebase Realtime Database.
* **Autenticação Segura:** Login com conta do Google, garantindo o isolamento dos seus dados por usuário.
* **Layout Responsivo:** Desenvolvido com Tailwind CSS para desktop e dispositivos móveis.

## 🛠️ Tecnologias
* HTML5 / JavaScript (ES6)
* Tailwind CSS
* Firebase Authentication & Firebase Realtime Database
